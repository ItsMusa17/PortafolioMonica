Traversal Sequences Blocked — Absolute Path Bypass

La aplicación bloquea las secuencias de recorrido ../, pero acepta rutas absolutas: basta pedir /etc/passwd directamente para evadir el filtro.

__ / __ / 2026 Nivel: Apprentice Burp Suite

Introducción

En este laboratorio de la Web Security Academy la tienda carga las imágenes con un parámetro filename. A diferencia del caso simple, sí hay una defensa: se bloquean las secuencias ../. La debilidad es que la aplicación interpreta el nombre como relativo a un directorio de trabajo y no impide rutas absolutas, así que una ruta que empieza desde la raíz escapa del directorio sin usar recorrido relativo.

Objetivo

Leer /etc/passwd evadiendo el filtro que bloquea ../, aprovechando que la aplicación acepta una ruta absoluta.

El laboratorio

Este reto pertenece a la Web Security Academy de PortSwigger. Puedes abrirlo aquí:

¿Qué es y por qué ocurre?

Una defensa por lista negra que solo busca y bloquea ../ es incompleta: la lectura arbitraria no exige recorrido relativo. Si la aplicación también acepta rutas absolutas, el archivo objetivo puede referenciarse directamente desde la raíz del sistema, sin escribir un solo ..

Clasificación: CWE-22 · OWASP A01: Broken Access Control.

Procedimiento

  1. Iniciar el laboratorio y abrir la tienda en el navegador integrado de Burp (Proxy → «Open Browser»).
  2. Abrir un producto con «View details» y localizar en Proxy → HTTP history la petición que carga la imagen.
  3. Enviar la petición a Repeater (clic derecho → «Send to Repeater»).
  4. Comprobar que ../../../etc/passwd es rechazado (el filtro bloquea ../).
  5. Sustituir el valor por la ruta absoluta y enviar.
  6. Confirmar 200 OK con el contenido de /etc/passwd y verificar «Lab Solved».

El payload

El valor que se inyecta en el parámetro del nombre de archivo es:

/etc/passwd

El / inicial marca la ruta como absoluta: el sistema de archivos la interpreta desde la raíz e ignora el directorio de trabajo base. Al no contener ../, evade por completo el filtro que solo busca recorrido relativo.

Mitigación

  • Rechazar rutas absolutas: descartar cualquier valor que comience por / (o \).
  • No usar listas negras como único control: bloquear solo ../ es evadible con rutas absolutas o codificación.
  • Canonicalizar y verificar el contenedor: resolver la ruta final y comprobar que sigue dentro del directorio base permitido.
  • Referencias indirectas: exponer un identificador que el servidor mapee a la ruta física real.

Conclusión

Aunque la aplicación bloquea ../, la lectura arbitraria se logró igualmente enviando la ruta absoluta /etc/passwd. Las listas negras son frágiles; el control correcto es la validación por lista blanca junto con la canonicalización y la verificación del directorio contenedor.
