El sello roto:
explotación de una máquina virtual

Un ejercicio controlado de intrusión: vulnerar una máquina virtual protegida con contraseña, paso a paso, para comprender cómo piensan los atacantes y cómo defenderse de ellos.

ObjetivoObtener acceso total
EntornoMáquina virtual aislada
HerramientasKali Linux · VirtualBox
NivelIntermedio

I. Sobre el proyecto

Este proyecto documenta el proceso completo de explotación de una máquina virtual protegida con contraseña, dentro de un laboratorio totalmente aislado. El propósito no es únicamente “entrar”, sino entender cada etapa del ataque —desde el reconocimiento hasta la escalada de privilegios— y, a partir de ahí, reconocer qué controles habrían impedido cada paso.

Todo el trabajo se realizó con fines educativos, sobre una máquina de mi propiedad y sin conexión hacia Internet. El resultado se acompaña de un video demostrativo y un manual detallado que sirve como evidencia.

V. Conclusión

Explotar la máquina paso a paso dejó claro que muchas intrusiones no dependen de técnicas sofisticadas, sino de descuidos: contraseñas débiles, servicios expuestos y permisos mal configurados. Comprender el ataque desde el lado ofensivo es, al final, la mejor manera de aprender a defender: cada fase que logré completar señala exactamente dónde debía existir un control de seguridad.
