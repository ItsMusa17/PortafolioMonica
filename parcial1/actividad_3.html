No presiones Esc... todavía

Implementar y documentar un programa en Python capaz de registrar eventos del teclado y almacenar la información de forma persistente.

  1. Inicio

Introducción

En esta actividad se desarrolla un programa en Python para detectar y registrar eventos del teclado mediante la librería pynput. El programa identifica cuándo una tecla es presionada o liberada, asigna una fecha y hora a cada evento y almacena la información de manera persistente en un archivo local.

Objetivo

Implementar y comprender el funcionamiento de un sistema de registro de eventos del teclado, incorporando persistencia de datos, asociación temporal e identificación individual de cada evento generado durante la ejecución del programa.

Codigo

# Importa las clases necesarias de pynput para detectar eventos del teclado
from pynput.keyboard import Key, Listener
# Importa la función datetime para obtener la fecha y hora actual
from datetime import datetime
# Variable global que almacena la cantidad de eventos registrados
contador_eventos = 0


#Crea un identificador único y consecutivo para cada 
#eventoregistrado en el teclado.
def generar_evento():
    global contador_eventos

    # Aumenta el contador cada vez que ocurre un evento
    contador_eventos += 1
    # Devuelve el identificador con tres dígitos
    return f"evento_{contador_eventos:03d}"


#Guarda la información del evento ocurrido dentro de un archivo de texto llamado "Eventos.txt".
def guardar_evento(tipo_evento):

    # Obtiene la fecha y hora actual 
    fecha_hora = datetime.now().strftime("%Y-%m-%d %H:%M:%S")

    # Genera un identificador para este evento
    evento = generar_evento()

    # Abre el archivo y agrega información sin borrar datos previos
    with open("Eventos.txt", "a", encoding="utf-8") as archivo:

        # Escribe la información del evento en una nueva línea
        archivo.write(
            f"{fecha_hora} | {tipo_evento} | {evento}\n"
        )

# Se ejecuta automáticamente cuando se presiona una tecla.
def on_press(key):

    try:
        # Si es una tecla alfanumérica muestra el carácter
        print(f"Tecla alfanumérica presionada: {key.char}")

    except AttributeError:
        # Si es una tecla especial 
        print(f"Tecla especial presionada: {key}")

    # Guarda el evento de tipo PRESS en el archivo
    guardar_evento("PRESS")

# Se ejecuta automáticamente cuando una tecla deja de estar presionada.
def on_release(key):

    # Muestra en consola la tecla liberada
    print(f"Tecla liberada: {key}")

    # Guarda el evento de tipo RELEASE en el archivo
    guardar_evento("RELEASE")

    # Si la tecla liberada es ESC finaliza el programa
    if key == Key.esc:
        return False

# Listener mantiene activo el monitoreo del teclado y llama automáticamente a las funciones:
with Listener(
    on_press=on_press,
    on_release=on_release
) as listener:

    # Mantiene el programa ejecutándose esperando eventos
    listener.join()

Conceptos principales

Eventos del teclado

Son acciones detectadas cuando una tecla es presionada o liberada. Mediante Listener de pynput, el programa puede ejecutar automáticamente funciones asociadas a cada evento.

Persistencia de datos

Consiste en almacenar los eventos registrados en un archivo local para conservar la información incluso después de finalizar la ejecución del programa. En esta actividad los datos se guardan en Eventos.txt.

Aprendizajes obtenidos

  • Aprendí a detectar eventos del teclado en Python utilizando las clases Key y Listener de la librería pynput.
  • Comprendí cómo almacenar información de manera persistente, agregando fecha, hora e identificadores únicos a cada evento registrado.

Conclusión

Esta actividad me permitió comprender el manejo de eventos y funciones automáticas en Python, así como la importancia de almacenar la información generada durante la ejecución de un programa. Además, aprendí a asociar cada evento con una fecha, hora e identificador para mantener los registros organizados y facilitar su análisis.
