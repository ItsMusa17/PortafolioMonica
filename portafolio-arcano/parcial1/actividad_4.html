Una página demasiado convincente

Simulación de un ataque de phishing en un entorno controlado utilizando Social-Engineer Toolkit (SET), con el objetivo de analizar la captura de credenciales ficticias e identificar medidas para prevenir este tipo de amenazas.

Introducción

En esta actividad se realizó una simulación controlada utilizando Social-Engineer Toolkit (SET) y el módulo Credential Harvester, con el fin de observar cómo funciona este tipo de ataque y reconocer las señales que pueden ayudar a identificarlo y prevenirlo.

Objetivo

El objetivo de esta práctica fue implementar y analizar, dentro de un entorno de laboratorio controlado, una simulación de ingeniería social utilizando Social-Engineer Toolkit (SET) y su módulo Credential Harvester Attack Method.

Simulación: cómo se capturan las credenciales

Cuando la víctima escribe su usuario y contraseña en la página falsa, el navegador envía esos datos mediante una petición HTTP POST al servidor del atacante (SET), que los registra en texto plano. Prueba a escribir cualquier dato de ejemplo y pulsa Iniciar sesión para ver el flujo paso a paso.

Conceptos principales

Phishing

Técnica de ingeniería social que busca engañar a una persona para que proporcione información sensible, como usuarios, contraseñas o datos personales.

Social-Engineer Toolkit (SET)

Herramienta utilizada para realizar simulaciones y pruebas relacionadas con ingeniería social dentro de entornos controlados.

Credential Harvester

Módulo que permite observar cómo los datos introducidos en un formulario pueden ser recibidos y registrados por un servidor.

Entorno controlado

Ambiente de laboratorio donde se realizan pruebas sin afectar sistemas, cuentas o usuarios reales.

Aprendizajes obtenidos

  • Comprensión del funcionamiento básico de un ataque de phishing.
  • Identificación de las principales características de una página web fraudulenta.
  • Uso de Social-Engineer Toolkit (SET) dentro de un entorno controlado.
  • Conocimiento del funcionamiento del módulo Credential Harvester.
  • Reconocimiento de los riesgos asociados al robo de credenciales.

Conclusión

Esta actividad permitió comprender de manera práctica cómo funciona un ataque de phishing y cómo una página aparentemente legítima puede utilizarse para obtener información sensible. Mediante el uso de Social-Engineer Toolkit y Credential Harvester en un ambiente controlado, fue posible observar el proceso de captura de credenciales ficticias y analizar los riesgos que representa este tipo de amenaza.
