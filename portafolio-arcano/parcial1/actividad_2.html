Introducción

En esta actividad se desarrolla la estructura inicial del portafolio digital de la asignatura de Seguridad Informática. El propósito es crear un sitio web funcional, accesible y organizado que permita presentar información académica y almacenar las evidencias de las actividades realizadas durante el curso.

Objetivo

Diseñar, implementar y publicar la estructura base de un portafolio digital mediante un sitio web funcional, estableciendo una navegación clara, una identidad académica y una organización adecuada para integrar progresivamente las evidencias del curso.

Conceptos principales

Portafolio digital

Sitio web utilizado para organizar, documentar y presentar las actividades, proyectos y evidencias desarrolladas durante la asignatura.

Desarrollo web

Uso de tecnologías como HTML, CSS y JavaScript para construir la estructura, el diseño y la funcionalidad del portafolio, permitiendo que sea accesible mediante una URL pública.

Aprendizajes obtenidos

  • Aprendí a crear y organizar la estructura base de un sitio web destinado a funcionar como portafolio digital académico.
  • Comprendí la importancia de mantener una navegación clara, una presentación profesional y una estructura preparada para integrar nuevas actividades durante el curso.

Conclusión

Esta actividad me permitió establecer la base de mi portafolio digital y comprender la importancia de organizar correctamente la información dentro de un sitio web. Además, pude aplicar conocimientos de desarrollo web para crear un espacio accesible y estructurado donde se documentarán las evidencias y aprendizajes obtenidos durante la asignatura.
